# Сайт svetlamp51.ru: всё, что изменено, и как это поставить

Инструкция для администратора сайта. В ней собраны все изменения нового дизайна: какие файлы заменить, какие модификации установить и что настроить в админке. По ней можно поставить всё заново в любой момент: после переезда на другой хостинг, после обновления ocStore или если что-то сломалось.

Магазин: **ocStore 2.3.0.2.2**. Тема: **svetlamp**. Админка: `https://svetlamp51.ru/admin`.

## 2. Что изменено на сайте

**Оформление**

- Новая главная: верхняя строка с адресом и телефоном, шапка с кнопкой «Каталог» и поиском, пять кнопок направлений, баннер со шкалой цветовой температуры, каталог плитками, подбор ламп по цоколю, «Рекомендуем», выставочный зал с картой, подвал.
- Под логотипом подпись «всё для монтажа натяжных потолков и окон в Мурманске».
- Все внутренние страницы (категории, товар, поиск, статьи, контакты) оформлены так же, как главная.
- Кнопок «В корзину» и «Купить в 1 клик» нет нигде. Форма обратной связи на странице «Контакты» убрана.

**Страницы категорий**

- Левой колонки (старый фильтр и список категорий) нет, товары на всю ширину.
- Подкатегории показаны крупными плитками с рисунками.
- Название страницы не повторяется в строке навигации над заголовком.
- Плитки товаров всегда одного размера, без звёзд рейтинга.
- **Фильтр по характеристикам** над товарами: мощность ламп, мощность и напряжение блоков питания. Если мощностей в категории больше восьми, вместо кнопок показывается ползунок «от … до».
- В разделе «Разное» вместо плитки «Химия» показываются её подкатегории, сразу после «Крепежа».

**Фото товаров**

- **Водяной знак «СветЛамп51»** по диагонали, очень светлый. Ставится только у товаров с галочкой «Водяной знак» в карточке. Оригиналы фото не меняются.

## 3. Какие файлы магазина затронуты

**Заменяются архивом темы** (`1-tema/svetlamp-dlya-zagruzki.zip`):

- папка `catalog/view/theme/svetlamp/` целиком: новая тема, старая тема `default` остаётся на месте;
- **один файл самого магазина:** `catalog/controller/common/home.php` (главная страница, блок «Рекомендуем»).

**Меняются модификациями** (файлы на сервере не трогаются, изменения хранятся в базе и применяются кнопкой «Обновить»):

| Модификация | Что делает | Какие файлы магазина правит |
|---|---|---|
| `svetlamp-kartinki.ocmod.xml` — «СветЛамп: картинки в плитках подкатегорий» | передаёт картинку подкатегории в плитку | `catalog/controller/product/category.php` |
| `svetlamp-himiya.ocmod.xml` — «СветЛамп: подкатегории «Химии» в разделе «Разное»» | плитки «Химии» в «Разном» после «Крепежа» | `catalog/controller/product/category.php` |
| `svetlamp-filtr.ocmod.xml` — «СветЛамп: фильтр по мощности и напряжению» | фильтр над товарами | `catalog/controller/product/category.php`, `catalog/model/catalog/product.php` |
| `svetlamp-znak.ocmod.xml` — «СветЛамп: водяной знак на фото товаров» | галочка в карточке товара и сам знак | `admin/controller/catalog/product.php`, `admin/model/catalog/product.php`, `admin/view/template/catalog/product_form.tpl`, `catalog/model/tool/image.php` |

**База данных**

- В таблице товаров `oc_product` появляется поле `sl_watermark` (галочка водяного знака). Его создаёт модификация сама, когда в админке первый раз открывают товар на редактирование.
- Остальные изменения в базе — это данные: привязка товаров к категориям, значения атрибутов «Мощность», «Напряжение». Их делали скриптами из папки `4-sql` (раздел 9), повторять при переустановке не нужно.

## 4. Полная установка с нуля

Порядок важен. Делайте по шагам и не пропускайте.

### Шаг 1. Резервная копия
Панель хостинга → «Резервные копии» → копия **файлов и базы данных**. Если такого раздела нет: в админке **Система → Обслуживание → Резервное копирование**, отметить все таблицы, скачать файл; плюс архив папки `catalog` из корня сайта.

### Шаг 2. Файлы темы

1. Откройте в файловом менеджере **корень сайта**: папку, где лежат `admin`, `catalog`, `image`, `system`, `index.php`, `config.php`.
2. Скачайте себе на всякий случай старый `catalog/controller/common/home.php`.
3. Загрузите в корень `svetlamp-dlya-zagruzki.zip` и распакуйте **прямо в корне**. На вопрос о замене файлов отвечайте «Заменить».
4. Удалите архив из корня.
5. Проверьте: есть папка `catalog/view/theme/svetlamp/`, в ней папки `fonts`, `image`, `javascript`, `stylesheet`, `template`.

> Если архив распаковался в лишнюю папку (например, `svetlamp-dlya-zagruzki/catalog/...`), перенесите содержимое так, чтобы папка `catalog` из архива совпала с папкой `catalog` сайта.

### Шаг 3. Включить тему

1. Админка → **Дополнения → Дополнения**.
2. В поле с типом дополнений выберите **«Шаблоны»** и нажмите серую кнопку **«Фильтр»**.
3. Карандаш у строки **«Тема по умолчанию»**.
4. В поле «Каталог темы» выберите **`svetlamp`**, «Статус» — «Включено». **Сохранить**.

### Шаг 4. Модификации
Для каждого из четырёх файлов из папки `2-modifikacii`:

1. **Дополнения → Установщик дополнений** → «Загрузить» → выбрать файл.
2. Дождаться зелёной полосы «Успешно».

Порядок установки любой. После всех четырёх: **Дополнения → Менеджер дополнений** → голубая кнопка **«Обновить»** вверху справа.

> **Важно про имена файлов.** Установщик принимает только файлы, имя которых заканчивается ровно на `.ocmod.xml`. Если браузер при скачивании добавил к имени `(1)` — например, `svetlamp-znak.ocmod (1).xml` — переименуйте файл, иначе будет ошибка «Неверный тип файла!».

### Шаг 5. Включить поле водяного знака
Откройте **любой товар** в админке на редактирование (Каталог → Товары → карандаш) и нажмите «Сохранить» или просто закройте. При первом открытии модификация сама добавит в базу поле для галочки. На вкладке «Данные», над «Статусом», должна появиться строка **«Водяной знак»**.

### Шаг 6. Отключить «Купить в 1 клик»
**Дополнения → Дополнения → Модули → Фильтр** → карандаш у **«Buy in one click by Wadamir»** → «Статус: Отключено» → Сохранить. Тема кнопку и так прячет, но модуль лучше выключить.

### Шаг 7. Проверить
Откройте сайт в режиме **инкогнито** (Ctrl+Shift+N) и пройдите по списку в разделе 10.

## 5. Настройки в админке (что берётся из данных магазина)

### «Рекомендуем» на главной
**Дополнения → Дополнения → Модули → Фильтр** → «Рекомендуемые» → карандаш у строки модуля.

- **Товары** — список товаров блока; порядок как в поле. Лучше всего смотрятся 4.
- **Лимит** — сколько показывать. **Статус** — «Включено».
- Модуль должен стоять в **Дизайн → Макеты → Главная** в позиции **«Верх страницы»**: тема берёт товары только оттуда.

### Картинки подкатегорий
Каталог → Категории → подкатегория → вкладка **«Изображение»** → загрузить файл из папки `3-kartinki` → Сохранить. Какие файлы к каким подкатегориям — в разделе 8. Если картинки нет, в плитке показывается стрелка.

### Водяной знак

- **Одному товару:** карточка товара → «Данные» → галочка **«Водяной знак»** → Сохранить.
- **Всем товарам сразу:** phpMyAdmin → вкладка SQL → текст файла `4-sql/znak-vsem-tovaram.sql`. Снять со всех — `snyat-znak-so-vseh.sql`.
- Знак ставится на копии фото, которые магазин делает для показа (папка `image/cache`). Оригиналы в `image/catalog` не меняются.
- Почти белый фон фото с галочкой автоматически делается чисто белым, чтобы на белой карточке не было видно разводов от сжатия.
- На маленьких превью (меньше 120 пикселей) знака нет.

### Фильтр по характеристикам
Фильтр строится из **атрибутов товара** (вкладка «Атрибуты» в карточке). Он узнаёт атрибуты **по названию**:

| Атрибут | Строка в фильтре | Пример значения |
|---|---|---|
| **Мощность лампы** | Мощность (у ламп) | `7`, `9.5` |
| **Мощность** | Мощность (у блоков питания и др.) | `60`, `100` |
| **Напряжение** | Напряжение | `12`, `24`, `220` |

- Значение лучше записывать **только числом**, без «Вт» и «В». Фильтр понимает и «10W», «220В», «9,5 Вт», но по единообразным данным легче искать ошибки.
- Блоки питания: в «Напряжении» только **выходное** напряжение (12, 24, 48), не «12/220».
- Строка фильтра появляется сама, если в категории у товаров хотя бы **два разных** значения. Если мощностей больше восьми — ползунок.
- Переименуете атрибут — фильтр перестанет его видеть.

### Адреса категорий, от которых зависят модификации и тема
Эти адреса (ЧПУ, поле «SEO URL» категории) **нельзя менять**, иначе часть функций перестанет работать:

| Адрес | Где используется |
|---|---|
| `raznoe-dlya-montazha`, `himiya`, `krepezh` | плитки «Химии» в «Разном» |
| `lampy/cokol-gx53`, `lampy/cokol-GU53`, `lampy/cokol-gu10`, `lampy/cokol-e14`, `lampy/cokol-e27`, `lampy/cokol-g9`, `lampy/cokol-g4`, `lampy/cokol-g13` | кнопки подбора по цоколю на главной |
| все адреса в меню «Каталог», кнопках направлений и плитках главной | ссылки (см. `5-instrukcii`) |

Если адрес всё же поменялся — поправьте ссылку по инструкциям из `5-instrukcii` или попросите разработчика.

### Подвал и контакты

- Ссылки «О компании», «Реквизиты», «Политика конфиденциальности» в подвале — из **Каталог → Статьи** (у статьи отмечен показ в подвале, порядок — поле «Порядок сортировки»).
- Телефон, адрес, e-mail на странице «Контакты» — из **Система → Настройки → Магазин** (вкладка «Магазин»).
- Телефон, адрес и часы в шапке и подвале записаны в теме: `template/common/header.tpl` и `footer.tpl`.

## 6. Как обновить, когда приходит новая версия темы

1. Загрузите новый `svetlamp-dlya-zagruzki.zip` в корень и распакуйте **с заменой**.
2. Менеджер дополнений → **«Обновить»**.
3. Откройте сайт по **Ctrl+F5** или в инкогнито.

**Если вы сами правили** `header.tpl` (меню «Каталог») или `home.tpl` (плитки главной) — новый архив сотрёт эти правки. Перед установкой сообщите разработчику, что меняли, чтобы правки попали в новую версию.

## 7. Как обновить модификацию

Если пришла новая версия модификации с тем же названием:

1. **Менеджер дополнений** → галочка у старой → красная кнопка **с корзиной** → подтвердить.
2. **Установщик дополнений** → загрузить новую.
3. **Менеджер дополнений** → **«Обновить»**.

Без удаления старой будет ошибка «…уже использует уникальный ID код…».

> **После обновления ocStore или модулей** (особенно OCFilter): снова распакуйте архив темы (обновление может вернуть старый `home.php`) и нажмите «Обновить» в Менеджере дополнений. Если после этого появится ошибка — удалите модификации СветЛамп, нажмите «Обновить» и обратитесь к разработчику: значит, обновление поменяло строки, к которым они привязаны.

## 9. Скрипты для базы данных (папка `4-sql`)

Запускаются в **phpMyAdmin → база сайта → вкладка «SQL»**: вставить текст файла → «Вперёд». Перед любым изменяющим скриптом сделайте резервную копию базы. Если таблицы начинаются не с `oc_`, замените `oc_` на свой префикс во всём тексте. Скрипты рассчитаны на MySQL 5.7 и новее.

| Файл | Что делает | Меняет данные? |
|---|---|---|
| `proverka-moshchnosti.sql` | у каких ламп не заполнена «Мощность лампы» | нет |
| `proverka-blokov-pitaniya.sql` | какие атрибуты заполнены у блоков питания | нет |
| `zapolnit-moshchnost-v2.sql` | заполняет пустую «Мощность лампы» по названию товара (11w → 11) | да, отмена: `otmenit-moshchnost.sql` |
| `bloki-pitaniya-ispravit-v2.sql` | блоки питания: напряжение и пустая мощность по названию | да, отмена: `bloki-pitaniya-otmenit.sql` |
| `napryazhenie-ispravit.sql` | блоки питания: «12/220» → 12, «48V» → 48 | да, отмена: `napryazhenie-otmenit.sql` |
| `napryazhenie-tolko-cifry.sql` | все товары: «220В» → 220 | да, отмена: `napryazhenie-tolko-cifry-otmenit.sql` |
| `ubrat-tovary-iz-golovnyh.sql` | убирает товары из категорий, у которых есть подкатегории (если товар есть ещё где-то) | да, отмена: `vernut-kak-bylo.sql` |
| `perenos-ulichnoe-v-sadovoe.sql` | товары только из «Уличного освещения» → «Садовое освещение» | да, отмена: `vernut-ulichnoe.sql` |
| `znak-vsem-tovaram.sql` / `snyat-znak-so-vseh.sql` | галочка водяного знака у всех товаров / снять | да |

Отмена работает, только пока в базе лежит резервная таблица, которую создал скрипт (`sl_…_backup`). Не удаляйте эти таблицы, пока не убедились, что всё в порядке.

## 11. Если что-то не так

| Что видите | Что сделать |
|---|---|
| Сайт выглядит по-старому | Инкогнито / Ctrl+F5. Проверьте шаг 3 (тема `svetlamp`) и нажмите «Обновить» в Менеджере дополнений. |
| «Неверный тип файла!» в установщике | В имени файла лишнее, например `(1)`. Имя должно кончаться на `.ocmod.xml`. |
| «…уже использует уникальный ID код…» | Сначала удалите старую версию модификации (раздел 7). |
| Нет плиток/фильтра/знака после установки модификации | Менеджер дополнений → «Обновить»; затем Ctrl+F5. |
| Нет строки «Водяной знак» в карточке товара | Модификация знака не установлена или не нажато «Обновить». |
| Знак не появился у товара с галочкой | Нет шрифта: проверьте `catalog/view/theme/svetlamp/fonts/onest-semibold.ttf` (распакуйте архив темы заново). Затем очистите `image/cache`. |
| В фильтре две одинаковые кнопки или лишние значения («12/220») | Значения атрибута записаны по-разному — исправьте в товарах или скриптами из раздела 9. |
| Ссылка открывает «Страница не найдена» | Поменялся адрес категории — поправьте ссылку (папка `5-instrukcii`). |
| Белый экран или ошибка на категориях | Удалите модификации СветЛамп по одной (раздел 7), каждый раз нажимая «Обновить», — так найдёте виновную. Сообщите разработчику текст ошибки. |

### Кэш картинок
Копии фото лежат в `image/cache`. Чтобы магазин сделал их заново (например, после смены водяного знака), удалите **всё содержимое** `image/cache`, но **не саму папку**. Папку `image/catalog` (оригиналы) не трогать. Первые открытия страниц после этого будут чуть медленнее.

### Откат

- **Вид сайта:** Дополнения → Шаблоны → «Тема по умолчанию» → каталог темы `default` → Сохранить → «Обновить».
- **Функция:** удалить нужную модификацию в Менеджере дополнений → «Обновить».
- **Полностью:** вернуть сохранённый `catalog/controller/common/home.php` и/или восстановить резервную копию из шага 1.
