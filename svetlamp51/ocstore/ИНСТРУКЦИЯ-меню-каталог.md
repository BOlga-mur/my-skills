# Как самой поменять меню «Каталог»

Меню «Каталог» открывается тёмной кнопкой слева от строки поиска. В админке магазина его настроить нельзя: оно записано в одном файле темы. Ниже описано, как в этом файле переименовать пункт, поменять ссылку, добавить, удалить или перенести пункт, а также сделать новый блок.

## 1. Где лежит файл

```
catalog/view/theme/svetlamp/template/common/header.tpl
```

Открыть его можно в файловом менеджере хостинга: зайдите в папку сайта (там же лежат `index.php` и `config.php`), потом по очереди в папки `catalog` → `view` → `theme` → `svetlamp` → `template` → `common`. Откройте файл `header.tpl` встроенным редактором (обычно кнопка «Редактировать» или «Правка»).

**Перед любой правкой сделайте копию файла.** Скачайте его на компьютер или скопируйте рядом под именем `header-kopiya.tpl`. Если что-то пойдёт не так, верните копию на место.

## 2. Как найти меню в файле

Нажмите в редакторе поиск (обычно Ctrl+F) и введите `Колонка 1`. Меню начинается с этой строки:

```html
      <!-- ===== Колонка 1 ===== -->
```

Всего колонок четыре, у каждой своя метка: `Колонка 1`, `Колонка 2`, `Колонка 3`, `Колонка 4`. Меню заканчивается после четвёртой колонки. Всё, что выше и ниже, трогать не нужно.

## 3. Из чего состоит меню

Вот начало первой колонки:

```html
      <!-- ===== Колонка 1 ===== -->
      <div>
        <h3><a href="osveshchenie">Освещение</a></h3>
        <ul>
          <li><a href="trekovye-svetilniki">Трековые системы</a></li>
          <li><a href="svetodiodnaja-lenta">Светодиодная лента</a></li>
          ...
        </ul>
        <h3><a href="elektrika">Электрика</a></h3>
      </div>
```

Строки бывают трёх видов:

| Строка | Что это на сайте |
|---|---|
| `<h3><a href="адрес">Название</a></h3>` | **Жирный заголовок**: название блока («Освещение») или выделенная категория («Электрика», «Крепёж») |
| `<li><a href="адрес">Название</a></li>` | **Обычный пункт** серым цветом внутри блока |
| `<ul>` и `</ul>` | Начало и конец списка обычных пунктов. Пункты `<li>` всегда стоят между ними |

Колонка целиком находится между `<div>` и `</div>`.

**Порядок на сайте такой же, как порядок строк в файле.** Чтобы поднять пункт выше, поставьте его строку выше.

## 4. Где взять адрес категории

1. Откройте нужную категорию на сайте.
2. Посмотрите на адресную строку браузера, например `https://svetlamp51.ru/raznoe-dlya-montazha/bytovaya-himiya`.
3. В меню нужна часть **после** `svetlamp51.ru/`. В примере это `raznoe-dlya-montazha/bytovaya-himiya`.

В начале адреса не должно быть ни `https://svetlamp51.ru/`, ни косой черты `/`.

Адрес нужно копировать, а не набирать вручную. Одна лишняя или пропущенная буква, и откроется «Страница не найдена» (так было с `teplyj-po` вместо `teplyj-pol`).

## 5. Частые правки

### Переименовать пункт

Меняйте только текст между `>` и `</a>`. Было:

```html
          <li><a href="ulichnoe-osveshhenie">Уличный свет</a></li>
```

Стало:

```html
          <li><a href="ulichnoe-osveshhenie">Уличное освещение</a></li>
```

### Поменять ссылку

Меняйте только то, что внутри кавычек после `href=`. Кавычки оставьте.

```html
          <li><a href="новый-адрес">Уличный свет</a></li>
```

### Добавить обычный пункт в блок

Скопируйте любую строку с `<li>` из этого блока, вставьте её новой строкой туда, где пункт должен стоять, и поменяйте адрес и название. Новая строка должна оказаться между `<ul>` и `</ul>`.

```html
        <ul>
          <li><a href="lampy">Лампы</a></li>
          <li><a href="nochniki">Ночники</a></li>
          <li><a href="Ljustry">Люстры</a></li>
        </ul>
```

### Удалить пункт

Удалите строку целиком, от `<li>` до `</li>` включительно.

### Перенести пункт в другой блок или колонку

Вырежьте строку целиком (Ctrl+X) и вставьте (Ctrl+V) в нужное место другого блока, между его `<ul>` и `</ul>`.

### Выделить пункт жирным, как основной блок

Пункт нужно превратить из `<li>` в `<h3>` и вынести за пределы списка, то есть ниже `</ul>` или выше `<ul>`. Было:

```html
        <ul>
          ...
          <li><a href="karnizy">Карнизы</a></li>
        </ul>
```

Стало:

```html
        <ul>
          ...
        </ul>
        <h3><a href="karnizy">Карнизы</a></h3>
```

### Сделать новый блок: заголовок со своим списком

Так устроен блок «Химия». Сначала идёт заголовок, сразу под ним список:

```html
        <h3><a href="himiya">Химия</a></h3>
        <ul>
          <li><a href="germetiki">Герметики, клей, жидкие гвозди, очистители</a></li>
          <li><a href="kosmofeny">Космофены</a></li>
        </ul>
```

Блок можно поставить в любую колонку: внутри её `<div>` … `</div>`, выше или ниже других блоков. Отступы между блоками сайт расставит сам.

Если у заголовка нет своей страницы, его можно сделать без ссылки:

```html
        <h3>Химия</h3>
```

## 6. Сохранить и проверить

1. Сохраните файл в редакторе.
2. В админке: Дополнения → Менеджер дополнений → голубая кнопка **«Обновить»** вверху справа. Без этого сайт может продолжать показывать старое меню: некоторые модули хранят свою копию шапки.
3. Откройте сайт и нажмите **Ctrl+F5**.
4. Откройте «Каталог» и пройдите по каждой ссылке, которую меняли.

## 7. Если что-то сломалось

- **Меню съехало, пропало или стало одной колонкой.** Скорее всего, удалён лишний `</div>`, `</ul>` или пункт `<li>` оказался вне `<ul>`. Верните копию файла из пункта 1 и повторите правку.
- **Ссылка ведёт на «Страница не найдена».** Проверьте адрес по пункту 4.
- **Изменений не видно.** Нажмите «Обновить» в Менеджере дополнений и откройте сайт по Ctrl+F5 или в режиме инкогнито.

## 8. Важно: новые версии темы

Если позже вы загрузите от меня новый архив темы (`svetlamp-dlya-zagruzki.zip`), файл `header.tpl` заменится и ваши правки меню пропадут. Поэтому, когда поменяете меню сами, пришлите мне файл `header.tpl` или просто перечислите, что изменили. Я внесу то же самое в свою копию, и следующий архив уже будет с вашими правками.
